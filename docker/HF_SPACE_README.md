# GenOffice Web

The world's first full-featured open-source AI Office suite, now available on the web!

## Features

- 📄 **Docs** - Word processor with .docx support
- 📊 **Sheets** - Spreadsheet editor with .xlsx support
- 📽️ **Slides** - Presentation editor with .pptx support
- 📕 **PDF** - PDF viewer and editor
- 📝 **Markdown** - Markdown editor

## About

GenOffice is a free, open-source alternative to Microsoft Office for macOS, Windows, and Linux, 
built around AI editing as a first-class workflow.

This Space runs the official GenOffice Docker image, providing full access to all applications
through a web interface.

## Usage

1. Select an application from the menu
2. Create or upload documents
3. Use AI-powered editing features
4. Download your work in standard formats

## Technical Details

- **Runtime**: Docker container
- **Port**: 7860 (Hugging Face Spaces default)
- **Source**: [GitHub Repository](https://github.com/genspark-ai/genoffice)
